# 👟 Loja Nike - Sistema de Gestão de Stock e Vendas

Projeto desenvolvido para a gestão do catálogo de produtos (Camiseta, Moletom e Tênis), abate automático de stock e relatórios visuais de vendas.

## 📁 Estrutura do Projeto
- `index.html`: Catálogo interativo de produtos e formulário de encomenda.
- `relatorios.html`: Painel com métricas, filtro por datas e gráfico de vendas (Chart.js).
- `app.js`: Lógica de negócio, abate de stock via `localStorage` e geração de gráficos.
- `style.css`: Estilização e identidade visual da marca Nike.
- `banco.sql`: Script de criação da base de dados SQLite (Tabelas de Produtos e Vendas).

## 🚀 Como Executar
1. Abre a pasta do projeto no **VS Code**.
2. Clica com o botão direito no `index.html` e seleciona **"Open with Live Server"**.
3. Realiza encomendas no catálogo para testar o abate de stock em tempo real e consulta a página de relatórios.
